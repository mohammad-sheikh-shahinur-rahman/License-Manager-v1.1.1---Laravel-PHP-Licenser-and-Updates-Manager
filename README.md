## ✨ About

License Manager is a powerful standalone software licensing system built with Laravel.

It supports:

- Product management
- License generation
- Activation tracking
- REST API
- Webhooks
- Envato integration
- Customer portal
- Update manager

---

## ⚙ Requirements

- PHP 8.2+
- MySQL 5.7+
- MariaDB 10.2+
- Composer
- Laravel 12 included

---

## 📦 Installation

Step 1

Download from CodeCanyon

Step 2

Upload to server

```
/public_html/license-manager/
```

Step 3

Open

```
https://your-domain.com/install
```

Step 4

Setup database & admin

Step 5

Login

```
https://your-domain.com/admin
```
